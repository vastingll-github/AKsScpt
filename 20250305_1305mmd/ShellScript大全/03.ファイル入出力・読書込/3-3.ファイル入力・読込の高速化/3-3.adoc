== シェルスクリプトでファイルを一行ずつreadする処理を高速化するテクニック

読込速度は前述しているので、ここではファイルを一行毎に処理するについてふれます。
bash
においてShellScriptでファイルを一行ごとに処理する場合、一般に使われているのは

ビルドインコマンド`read`です。この `read`は前述で遅かったですが一行づつ処理したい場合に使えるのは `read`
以外どのような方法があるでしょうか？
ファイルサイズによらず読込が速いのが、 `readarray` ですがメモリが十分な場合、配列にファイルすべてを読込み、`for`
を使うことで対応できます。

さて、以下の簡単な例で、配列のインデックスを利用しbashでgrepを実現する10行程度のスクリプトです。

readarray.bash

----
#!/usr/bin/env bash
#
readarray -t onelines < "$1"
for i in "${!onelines[@]}"
do
  if [[ $onln =~ "$2" ]];then
    printf "%6s: %s" $i $onelines[$i]
  fi
done
----

複数行に跨るキーワードを検索するスクリプトです。
検索結果の表示がgrep とは違います。
配列を注意深く連結しその中からキワードを探します。少し遅いですが実行する行がので、
pcre2grep -M 正規表現が使えますが、こちらは検索対象は文字列のみです。

multilinesearch.bash

----
#!/usr/bin/env bash
#
readarray -t onelines < "$1"

# 配列を読込でIFSで繋げられる”スペース”を削除するため設定方法
IFS=''

# Bash配列を1変数にする時、配列の展開結果がスペースで区切られるを防ぐため、@ の代わりに * を使い、全体をダブルクォーテーションで囲む必要あり
alllines="${onelines[*]}"

while [[ ${alllines} =~ "$2" ]]; do
  # [[ ... =~ ... ]] でパターンマッチングし、組込み変数 BASH_REMATCH を活用
  match_txt="${BASH_REMATCH[0]}"
  # 先頭から一番短いキーワード迄の文字を削除して残り文字列を変数取得
  # 一致位置を計算（${alllines%%$match_txt*}。マッチ部分手前の文字列長を計算可能）
  # 以下は一致した位置より後の文字列を取得する
  afstr=${alllines#*${match_txt}}
  apos=$((${#afstr}))
  echo "Keyword[${match_txt}] 後の(改行を含ま無い)12バイト文字:${afstr:0:12}"
  # 見つけたキーワードより後の文字列に検索範囲を絞る。無限ロープ回避
  alllines="${alllines#*${match_txt}}"
done
----
